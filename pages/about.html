Our mission

Canada, made personal.

GED was built around a single question: what if planning a trip to Canada felt less like filling out a form and more like designing something that belongs to you?

✦

Curated, not crowded

We don't list everything. We list the things that actually matter — the places, events and stays worth building a trip around.

⛶

Built around you

Province, city, neighborhood, stay, transport, experiences and dining — every choice changes the itinerary and the estimated total.

⧉

Honest by design

Every price is illustrative, every score is explained and every route is labelled. This is a school project — and it says so everywhere.

How we got here

From idea
to itinerary.

GED was built in four stages — each one adding a layer of structure to an idea that started as a simple brief.

01

Research

Mapped provinces, cities, airports, events and attractions. Built the foundation of every dataset used today.

02

Architecture

Designed the seven-layer system: frontend, experience layer, data branches, normalization and the Smart Engine.

03

Experience

Built every page — flights, hotels, events, packages, about — with one consistent visual and interaction language.

04

Refinement

Added filters, comparisons, saved trips, modals and toasts. Turned a static site into a system that responds.

What we believe

Four values.
One product.

These aren't slogans. They're decisions we made every time we had to choose between "more" and "better".

✦

Clarity over volume

A curated set of places, events and routes beats an endless list every single time.

◎

Design is a service

Every animation, spacing and color choice exists to make the experience easier — never to show off.

⌘

Honest by default

Every price is fictional, every score is explained and the project never pretends to be a real agency.

⧉

Built to be used

The trip builder, the comparison tool and the saved trips are real features — not screenshots.

Why it matters

# GED Travel Agency — Structure

- `index.html`: cinematic home / Explore
- `pages/`: destinations, events, flights, hotels, packages, help, about, demo booking
- `css/`: visual system, Liquid Glass, animation and responsive modules
- `js/`: data and independent GED engines
- `data/`: JSON demo datasets
- `components/`: reusable component references
- `api/`: provider and normalization architecture
- `backend/`: optional Flask demonstration API
- `docs/`: project and technical documentation
